# LoveDA Dataset

## Nombre del dataset
LoveDA - A Remote Sensing Land-Cover Dataset for Domain Adaptive Semantic Segmentation

## Descripción general

LoveDA es un conjunto de datos de teledetección para la segmentación semántica adaptativa de dominio. Contiene 5,987 imágenes aéreas de alta resolución (1,024 × 1,024 píxeles, 0.3 m/píxel) recolectadas de dos dominios geográficos distintos — urbano y rural — en tres ciudades chinas. LoveDA fue creado específicamente para abordar el desafío del cambio de dominio (domain shift) entre escenas urbanas y rurales, sirviendo como benchmark para evaluar modelos de aprendizaje transferible en la clasificación de cobertura del suelo. El dataset plantea tres retos principales: objetos multi-escala, muestras de fondo complejas y distribuciones de clase inconsistentes entre dominios.
